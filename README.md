# yogalayout

RAII Python bindings for [Yoga](https://www.yogalayout.dev/) (v3.2.1, public C API only).

## License

MIT (see `LICENSE`). Yoga itself is also MIT-licensed; see `THIRD_PARTY_LICENSES.md`.

## Tests

`tests/conformance/` is generated by `tools/gen_conformance.py` from Yoga's own generated layout
tests (`extern/yoga/tests/generated`, MIT, Meta Platforms) so the binding is checked against
upstream's expected numbers. Regenerate after bumping the Yoga submodule.
